# Spring-WebApp
Project reviving former FrenChat, focusing on conversational language practice.

## Tech Stack
- **Frontend:** Vue 3 + Vite
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL
- **Hosting:** Railway
- **Source Control:** GitHub
- **IDE:** VSCode
- **Voice:** OpenAI Realtime API (ephemeral token approach)
